==> Latency

Latency = Time taken for a single request to get a response.

Example:

You open Google.
Request → Server → Response
If it takes 120 ms, then:
-> Latency = 120 ms

-> Example
Login API:

User clicks login
Response received in 150ms

-> So: Latency = 150 ms

-> Good systems aim for:
API latency: <200 ms
Page load: <2 seconds
